点击表格最后一行的「+ 添加一行」，逐门填写。周次写法：1-16、1-16单、1-8,10-16。

支持表头：课程名称,星期,节次,周次,教室,教师（顺序不限，可只给部分列）。

已经有 .ics（例如从 WakeUp 课程表、其他日历 App 导出的），可以直接反向导入，日期会按节次时间表自动换算成第几周。

脚本只在你自己的浏览器里读取当前页面，把课表表格 POST 到本站解析，不碰账号密码、不在服务器留数据。若教务系统开了严格 CSP 拦住了书签脚本，用方式 2。

方式 2 · 复制页面源码粘贴（最稳）

在课表页面按 Ctrl+U（或右键 → 查看网页源代码）后全选复制，粘到下面；直接选中课表表格复制也常常可以。

支持的教务系统

  • 正方教务（ZFSoft）：老版 xskbcx.aspx 课表表格；新版 kbList JSON（jwglxt/kbcx/...）
  • 强智科技（QZDatasoft）：/jsxsd/xskb/xskb_list.do（含一格多门课、单双周）
  • 青果软件（KINGOSOFT）、树维（SudyTech）、URP 综合教务、金智 / Wisedu 等「星期 × 节次」表格
  • 识别不出来也能试：任何标准课表表格都会走通用解析器；再不行就用「粘贴文本」

如果你学校的课表结构比较特别，把脱敏后的页面源码发个 issue，加一个适配器很快。

iPhone 上怎么加？（30 秒）
  1. 在 iPhone 的 Safari 里打开本页面，并用下面按钮生成链接。
  2. 点「① 直接订阅」会直接跳到日历订阅页；或者手动：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历，把「订阅地址」粘进去。
  3. 系统日历里就会出现课表，课前会按你设置的提前量提醒。
  4. 课表改了：回到本页改完再点「生成订阅链接」——如果订阅地址没变（内容相同），iPhone 会自己刷新；内容变了会生成新链接，需要在日历里把旧的删掉、加新的。

注意：订阅日历是只读的、同步有延迟（几小时到一天）；想立刻看到变化，可以用「下载 .ics 文件」再导入一次。

数据不上传服务器：课表被压缩后放在链接本身里（所以你的订阅地址就是数据）。不想要了就把链接销毁。
